# 2. Структура проекта
![](screenshots/02-folders.png)
## Ответ на вопрос: 

### Структура папок:

**app/** - своего рода ядро, в котором содержатся модели бд, контроллеры, правила доступа и middleware для кастомной обработки. По сути она отвечает за действия после поступления запроса.

**routes/** - маршрутизация отвечающая за определённо заданную обработку при переходи по конкретному URL.

**resources/views** - то где лежит фронтенд составляющая проекта, здесь же лежат blade-шаблоны и подставляются данные полученные от контроллеров.

**databases/** - всё про бд, её устройство, тестовые данные, генерация фейковых записей.

**public/** - по сути точка входа в приложение уже после которой Laravel решает что делать дальше + статика.
    
**Почему document_root должен быть на public/?:** Потому что там только безопасные файлы, если указать на корень, есть риск получить доступ к .env (secret и.т.д)

# 4. Новый конфиг nginx
![](screenshots/04-nginx-config.png)
## Ответ на вопрос:

try_files $uri $uri/ /index.php?$query_string позволяет Nginx самому отдавать статичный контент, не делаю лишние запросы на сервер за статикой.
    
Сначала он проверит может ли он вернуть запрашиваемый контент и если нет, то передаст управление в index.php с параметрами URL.
    
Без try_files Nginx будет делать запросы и за статическим контентом, тем самым бессмысленно нагружая сервер.
