session_destroy() удаляет данные сессии только на сервере, но не удаляет cookie в браузере. Поэтому браузер продолжает отправлять старый PHPSESSID.
Если после этого вызвать session_start(), PHP может создать новую сессию, потому что получает старый идентификатор, но не находит связанных данных.
Чтобы полностью завершить сессию, нужно удалить и cookie через setcookie() с истёкшей датой. Иначе в браузере останется устаревшая кука, которая будет отправляться на сервер и может приводить к созданию новых пустых сессий.
Если сделать только что-то одно например удалить только cookie, то на сервере останутся данные которые уже не будут использоваться.
